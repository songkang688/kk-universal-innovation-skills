## 三、网络结构创新点的五条硬标准

1. **单一核心机制（反 A+B 拼接）**：每套方案只能围绕**一个核心思想**展开，一句话能说清、写得出闭式数学公式、画得出清晰结构图、设计得出干净消融。若含 2 个紧密配合的子部件，必须各自配独立开关，严禁堆砌无关技巧。
2. **有近两年顶会顶刊的具体依据**：每套方案至少明确对标 **2 篇近两年（2024–2026）顶会顶刊真实论文**，写清：论文题目/出处/年份、借用了哪个具体算子或思想、原文解决什么问题、直接搬来本任务哪里水土不服、你做了什么本质改造。联网环境必须检索核实；离线未核实的必须标注 `[待联网核验]`，**绝对禁止编造论文、作者或实验数字**。
3. **推理期留在模型内，不偷改训练配方**：
   - 模块在推理部署时实际存在于网络中（纯损失、纯数据增强、纯标签分配归属训练策略，不算结构创新；若结构模块确需配套一项轻量辅助监督，必须做成独立开关并提供关掉该监督的对照）。
   - 优化器、学习率、训练轮数、数据增强、主损失函数保持与基线完全一致，确保公平对比。
4. **零侵入开关 + 第 0 步初始等价 + 零死梯度**：
   - 提供总开关（如 `--enable_<abbr> 0/1`）：置 `0` 时走官方基线原路径，前向输出与损失逐位一致。
   - 置 `1` 时尽量做到**最大程度复用预训练权重 + 第 0 步初始化与基线等价**，同时保证**所有新增可学习参数张量在第 0/1 步反传均具有非零梯度（严禁出现死门控或零梯度冗余参数）**。
   - 必须提供至少 1 个**等参数量退化证伪对照开关**（参数量与完整版完全一致，但切断核心几何/物理/跨层机制），用于证明涨点来自机制本身而非参数增加。
5. **开销红线与工程兼容**：
   - 部署态参数量与 FLOPs 增幅目标控制在 **5% 以内（硬上限 10%）**，同时实测算子真实前向/反向耗时（警惕低 FLOPs 但高碎片调度时延的慢算子）。
   - 必须完整通过 AMP 混合精度、EMA、`deepcopy`、算子融合（`fuse`）、权重保存与加载续训及优化器参数分组检查。

所有产出统一放在新建目录 `innovations/<日期>_<署名>_网络结构/` 下，**绝不修改原仓库任何已有文件**：

- `00_总说明与优先实验推荐.md`

## 五、快速自检与效率铁律（不跑训练！）

- **绝不启动正式训练或多轮微调实验**，不杀任何已有进程。
- 每写完一套方案的代码，立刻在后台异步启动 `check_self.py`（有空闲显卡则用显卡测几秒，否则用多线程 CPU 测），验证：模块导入、前向+损失+反传、开关置 `0` 逐位等价、开关置 `1` 新增参数零死梯度、AMP/EMA/存档读取正常、参数量/FLOPs/单步耗时实测。
- **异步不等待**：自检挂后台后立即写文档并推进下一套方案，全部做完后统一核对所有 `self_test.log` 全绿通过并输出总汇报。
